Requisitos Funcionais

RF01 — Exibir dashboard principal
O sistema deve apresentar uma tela principal com o nome do sistema, subtítulo e área de análise de crimes cibernéticos.

RF02 — Filtrar dados por ano
O sistema deve permitir que o usuário selecione um ano para visualizar as ocorrências correspondentes ao período escolhido.

RF03 — Filtrar dados por mês
O sistema deve permitir que o usuário selecione um mês para refinar a análise das ocorrências.

RF04 — Filtrar dados por tipo de crime
O sistema deve permitir que o usuário selecione o tipo de crime cibernético, como phishing, ransomware ou fraude digital.

RF05 — Aplicar filtros aos dados
O sistema deve possuir um botão para aplicar os filtros selecionados e atualizar os indicadores, gráfico, mapa e ranking.

RF06 — Exibir total de ocorrências
O sistema deve apresentar um indicador com o total de ocorrências registradas de acordo com os filtros aplicados.

RF07 — Exibir tipo de crime mais recorrente
O sistema deve apresentar o tipo de crime cibernético com maior número de registros no período analisado.

RF08 — Exibir ano com mais registros
O sistema deve apresentar o ano com maior quantidade de ocorrências registradas.

RF09 — Exibir gráfico principal
O sistema deve apresentar um gráfico principal para visualizar dinamicamente os dados filtrados por ano, mês e tipo de crime.

RF10 — Alterar visualização do gráfico
O sistema deve permitir alternar a visualização do gráfico entre linha, barra e pizza.

RF11 — Exibir mapa de ocorrências
O sistema deve apresentar um mapa para visualização geográfica das ocorrências por região ou estado.

RF12 — Permitir interação com o mapa
O sistema deve permitir interação básica com o mapa, como zoom e seleção de regiões para visualização de detalhes.

RF13 — Exibir ranking de regiões
O sistema deve apresentar um ranking das regiões ou estados com maior índice de crimes cibernéticos.

RF14 — Exibir dados do ranking
O ranking deve apresentar posição, região ou estado, tipo de crime, quantidade de ocorrências e índice.

RF15 — Atualizar os elementos da tela conforme os filtros
O sistema deve atualizar KPIs, gráfico, mapa e ranking conforme os filtros aplicados pelo usuário.

Requisitos Não Funcionais

RNF01 — Interface simples e organizada
O sistema deve possuir uma interface limpa, objetiva e de fácil compreensão.

RNF02 — Visualização em formato de dashboard
O sistema deve organizar as informações em formato de painel analítico, com filtros, indicadores, gráfico, mapa e tabela.

RNF03 — Dados públicos ou simulados
O sistema deve utilizar apenas dados públicos ou simulados, sem acesso a dados sigilosos.

RNF04 — Clareza na apresentação dos dados
O sistema deve apresentar os dados de forma visual, clara e compreensível para o usuário.

RNF05 — Responsividade
O sistema deve se adaptar a diferentes tamanhos de tela, especialmente desktop e notebook.

RNF06 — Manutenibilidade
O sistema deve possuir uma estrutura organizada para facilitar futuras alterações e melhorias.

RNF07 — Segurança conceitual do projeto
O sistema deve deixar claro que não realiza investigação criminal real, identificação de criminosos ou acesso a sistemas oficiais.

RNF08 — Desempenho adequado
O sistema deve carregar filtros, gráficos, mapa e ranking em tempo aceitável para uma aplicação web de análise.
