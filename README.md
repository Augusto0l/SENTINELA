# 🛡️ CyberCrime Monitor: Sistema de Monitoramento de Crimes Cibernéticos

Projeto pessoal desenvolvido com foco em análise de dados, segurança digital e visualização de informações públicas sobre crimes cibernéticos.

---

## 🧾 1. Descrição do Projeto

O **CyberCrime Monitor** é um sistema web desenvolvido para apoiar a análise e o monitoramento de crimes cibernéticos com base em dados públicos. O objetivo do projeto é organizar informações relacionadas a ocorrências digitais e apresentá-las em um dashboard com indicadores, filtros, gráficos e possíveis visualizações geográficas.

A plataforma será construída a partir de um banco de dados próprio, alimentado por dados públicos divulgados por fontes confiáveis. Esses dados servirão como base para consultas, análises estatísticas e construção dos gráficos do sistema.

O sistema permitirá visualizar informações como quantidade de ocorrências por ano e mês, tipos de crimes cibernéticos mais recorrentes, evolução dos registros ao longo do tempo e, caso os dados disponíveis permitam, a distribuição geográfica das ocorrências por estado ou região.

É importante destacar que o sistema não terá como finalidade realizar investigações criminais, identificar autores de crimes ou acessar dados sigilosos. O foco do projeto será exclusivamente acadêmico, analítico e estatístico, utilizando apenas dados públicos ou simulados para fins de estudo e desenvolvimento.

Dessa forma, o projeto busca criar uma ferramenta prática para análise de tendências em crimes cibernéticos, contribuindo para o aprendizado em segurança digital, banco de dados, desenvolvimento web e visualização de dados.

---

## 🎯 2. Objetivos Iniciais

Para a primeira fase deste projeto, o foco será estruturar os dados e criar um dashboard funcional para análise inicial das informações. Os objetivos são:

📊 **Coletar e estruturar dados:** organizar dados públicos relacionados a crimes cibernéticos, como phishing, golpes virtuais, fraudes digitais, vazamento de dados e outros tipos de incidentes.

🗄️ **Criar um banco de dados:** desenvolver uma base própria para armazenar os dados coletados, permitindo consultas, filtros e geração de gráficos.

📈 **Desenvolver um dashboard:** criar uma interface visual com KPIs, filtros e gráficos para facilitar a interpretação das ocorrências.

🔎 **Analisar os dados:** identificar padrões, tendências e categorias mais recorrentes de crimes cibernéticos ao longo do tempo.

🧭 **Validar a solução:** utilizar o dashboard como base para compreender a utilidade do sistema e planejar futuras melhorias.
