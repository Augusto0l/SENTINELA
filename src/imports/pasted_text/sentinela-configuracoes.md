# Prompt para Figma Make — Tela “Configurações” do SENTINELA

Crie uma tela web de dashboard chamada **“Configurações”** para o sistema **SENTINELA**, mantendo o visual **o mais fiel possível** à referência aprovada, com **layout dark mode moderno, profissional, institucional e sofisticado**, usando tons de **azul-marinho, preto azulado e cinza-escuro**, com **detalhes em azul vivo** para destaques e ações principais.

## Objetivo

Quero uma tela de **Configurações** com **excelente aproveitamento do espaço horizontal**, visual premium, organização clara e aparência de sistema real já pronto para uso.

## Diretriz principal

Use a **imagem de referência** como base principal e recrie a interface **praticamente igual**, preservando:

* a identidade visual do **SENTINELA**;
* o **menu lateral escuro**;
* a **barra superior com busca e perfil do usuário**;
* o título **“Configurações”**;
* a organização em **cards/painéis**;
* a disposição em **duas colunas**;
* os **campos, switches, botões e cartões**;
* o botão superior **“Salvar alterações”**.

## Estrutura geral

A tela deve ser em formato **desktop widescreen**, com:

* **sidebar fixa à esquerda**;
* **topbar horizontal**;
* **conteúdo principal centralizado e bem distribuído em duas colunas**, preenchendo melhor a tela.
